Original library archives remain outside the project in the session AudioSources folder. Only these selected compressed effects ship. Kenney licence texts are retained in Data/Licenses/Audio. No runtime library or package dependency was added.

Sources: https://kenney.nl/assets/interface-sounds ; https://kenney.nl/assets/ui-audio ; https://kenney.nl/assets/casino-audio ; https://kenney.nl/assets/rpg-audio . All CC0-1.0, by Kenney. Cafe ambience by gydisvyddhvduh, https://freesound.org/people/gydisvyddhvduh/sounds/855905/ , page declares Creative Commons 0. Public HQ preview downloaded from https://cdn.freesound.org/previews/855/855905_18351206-hq.mp3 (not the login-only original WAV).

Preparation: 32 kHz Ogg Vorbis, peak adjusted toward -8 dBFS before CSV attenuation, short edge fades, maximum 2 seconds for effects. Cafe excerpt: first 6 seconds, filtered 180–2200 Hz, 0.7-second fade-in and 2.2-second fade-out. Source Ogg files are stereo because the available native Vorbis encoder requires stereo; Unity forces mono. No intelligible speech is intentionally used as dialogue. Review the ambience by ear before release. Exact file hashes are in Tools/Art/SoundEffectSources_20261122.csv.

New physical sources: Paper page turn 1 by HenKonen (https://freesound.org/people/HenKonen/sounds/757221/) and Cash Register Fake by CapsLok (https://freesound.org/people/CapsLok/sounds/184438/).
